# Notas Importantes Sanitizadas

Este arquivo centraliza aprendizados reutilizaveis para agentes, sem caminhos absolutos, credenciais ou dados restritos.

## Agentes e Contexto

- O agente deve consultar documentacao de projeto antes de mudancas relevantes.
- O agente deve confirmar o estado real no repositorio antes de confiar em notas antigas.
- O agente deve registrar decisoes tecnicas de forma curta e rastreavel.

## Skills

- Skills obrigatorias devem ser revisadas antes de uso.
- O pacote bruto de skills e referencia; instalacao automatica integral exige revisao e aprovacao.
- Ao encontrar skills duplicadas, priorize a fonte canonica local definida pelo usuario no Mac.

## Seguranca

- Segredos ficam fora do Git.
- Configuracoes versionadas usam placeholders.
- Backups ou arquivos locais sensiveis nao devem ser copiados para o repositorio.

## Documentacao

- Prefira notas pequenas, orientadas a decisao.
- Use wikilinks para conectar projetos, tecnologias e aprendizados.
- Evite duplicar informacao que o agente pode ler diretamente no codigo.
