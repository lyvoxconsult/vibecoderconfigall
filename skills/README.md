## 🤖 Como os Agentes Carregam e Consomem as Skills

1. **Consulta Mandatória:** Antes de propor refatorações ou implementar novos fluxos de código, os agentes devem ler a skill técnica correspondente para se alinhar com a arquitetura padrão.
2. **Conformidade em Códigos:** Ao gerar novas rotas ou componentes front-end, o agente deve garantir que a entrega siga exatamente o padrão semântico, de tipagem ou de design especificado nas skills locais.
3. **Evitar Gambiarras:** O uso consistente de skills serve como barreira de segurança contra soluções frágeis e duplicações desnecessárias.
